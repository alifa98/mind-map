SMALL FOOTPRINT. BIG POTENTIAL.

Meet your new thinking tool.

A beautiful mind map in just a few lines. No dependencies required.

1. Install the library

npm install chic-mindmap

For this local package, run npm install /path/to/mind-map, or use the compiled files in dist/. Registry installation is available after publishing.

2. Give your ideas a home

<div id="mindmap-root" style="height: 600px"></div>

3. Make the connection

A little API. A lot of flexibility.

setTheme('dark')Light, dark, or in sync with your system.
setStyle('radial-classic')A fresh perspective, instantly.
setData(yourTree)Keep your ideas growing.
setConfig({ spacing: 1.2 })Dial in the details.
expandAll() · collapseAll()See the big picture or focus in.
fit() · zoomIn() · zoomOut()Find your perfect point of view.
exportSVG() · getData()Take your thinking with you.
destroy()Clean up listeners and observers.
Using a script tag instead?
<script src="dist/chic-mindmap.umd.js"></script>
<script>
  const map = new ChicMindmap.MindMap({
    container: document.querySelector('#mindmap-root'),
    data: { label: 'An idea', children: [{ label: 'A possibility' }] }
  });
</script>
